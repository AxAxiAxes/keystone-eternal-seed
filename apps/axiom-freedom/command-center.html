AXES Command Center

Private build-management view. It observes protected AXI data and public endpoint reachability; it does not create work, enable automation, deploy, publish, or change accounts.

Live continuity clock and checkpoints

Browser-local time updates every second. Timeline checkpoints are read from the versioned project record; the clock is not service uptime or an external deployment claim.

Build and efficiency signals

Efficiency describes recorded task/run flow only. It is not a measure of people, identity, value, or project worth.

Continuity tree

AXI root → governance → registered agents → assigned tasks → latest runs. Unassigned work remains visible.

Site development monitor

A 401 response for protected operator pages means the route is reachable and access-controlled. A 404 health route is an attention state, not proof that a site is unavailable.
