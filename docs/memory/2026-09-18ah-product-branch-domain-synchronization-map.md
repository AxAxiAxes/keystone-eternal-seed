# Product branch ↔ domain synchronization map created

**Date:** 2026-09-18

## What was requested

The founder asked to "research all tasks assigned and organise for
synchrosisity [synchronicity], identify each branch with domain names."

## What was done

- Created `docs/keystone/PRODUCT_BRANCH_DOMAIN_MAP.md`, a single
  cross-reference table mapping every active product/workstream ("branch")
  to its domain name(s), repo, live status, related
  `FOUNDER_ACTION_QUEUE.md` item number(s), and detail doc. Covers: AXES
  Contracting (`axescontracting.com`), XIIOM/AXIOM chat (`xiiom.com`), the
  first paid AXES consultation service, KEYSTONE creator-origin setup,
  AXOUS/AXOUX creator studio (`axoux.com`), AUXAOUS (`auxaous.com`), URNUR
  (`urnur.com`), Athanor (no domain assigned), Axaxar.com (`axaxar.com`,
  separate repo), and the Urartuhi gallery (`urartuhi.com`, separate repo,
  already live on GitHub Pages but not DNS-connected).
- **Gap found:** two repo-backed workstreams (Axaxar.com's draft plan,
  the Urartuhi gallery site) existed with their own repos/detail docs but
  were never added to `FOUNDER_ACTION_QUEUE.md`, making them invisible in
  the founder's single-page task view. Added as new queue items #10 and
  #11.
- Cross-linked the new map from the top of `FOUNDER_ACTION_QUEUE.md`.

## What was not done

No new domains were registered, no DNS was changed, and no new repos were
created — this pass only organizes and cross-links existing, already-known
branches/domains/repos so they stay synchronized with each other.

## Reference

- `docs/keystone/PRODUCT_BRANCH_DOMAIN_MAP.md` (new)
- `docs/keystone/FOUNDER_ACTION_QUEUE.md` (items #10, #11 added)
