## Memory-continuity safeguard implemented

A repository-based safeguard was added so a future request for "the
certificate" or "the document" can be answered quickly by whichever agent is
running then:

- A new "Founder quick answers" section was added near the top of
  [`docs/memory/README.md`](README.md), mapping this kind of request directly
  to the two files above.
- This is a real but bounded safeguard: it makes the answer easy to *find* in
  the repository (which every session is already required to read on
  startup). It does not give any individual chat session memory of a prior
  conversation it was not part of — no tool available to this project
  provides that, and no document claims otherwise.
