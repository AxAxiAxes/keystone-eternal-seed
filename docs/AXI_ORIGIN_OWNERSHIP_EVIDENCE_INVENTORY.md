## Control rule

No row may be added to the inventory table below unless every required
field has a specific, source-linked, dated answer. A founder recollection
without a source reference is recorded as "founder-reported, unverified" in
the evidence-integrity column, never upgraded to verified without an
independent check (file hash, timestamp, external record, or named
reviewer). Placeholder, narrative, projected, or extrapolated figures (for
example, the UI autonomy loss-model's per-user or population-wide totals)
must not be entered here as if they were counted losses; that model is
already tracked separately as internally-consistent-arithmetic-only in
`AXI_ETERNAL_ORIGIN_VALUE_AND_CRISIS_REGISTER.md`.
