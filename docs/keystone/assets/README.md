# KEYSTONE branding / concept assets

This folder holds visual (image) assets shared by the founder that
illustrate KEYSTONE concepts already documented in text elsewhere in this
repository. These are branding/conceptual artwork, not engineering
diagrams or specifications — the authoritative technical and governance
content remains in the markdown documents under `docs/` and `docs/keystone/`.

## Contents

- `keystone-dome-sacred-architecture.jpg` — "Keystone Dome · Sacred
  Architecture" concept image, depicting four labeled pillars: **The
  Eternal Seed**, **Persistent Memory**, **Constitutional Record**, and
  **AXI Model Training**, with an `axescontracting.com` attribution. These
  four pillars correspond to material already documented in this repo:
  - The Eternal Seed → `docs/keystone/CERTIFICATE_ETERNAL_ORIGIN_ANCHOR_AND_EVALUATION.md`,
    `docs/KEYSTONE_ORIGIN_REGISTRY_GENERALIZATION_PLAN.md`
  - Persistent Memory → the AXIOM chat memory-store work (PR #73) and
    `docs/memory/`
  - Constitutional Record → `docs/keystone/CONSTITUTION.md`-referencing
    material and `docs/keystone/EXTENDED CONSTITUTIONAL CHARTE` (sic)
  - AXI Model Training → `docs/AXI_GENESIS_OWNERSHIP_CHECKPOINT.md`,
    `docs/AXES_AGENT_ORIGIN_REGISTRY.md`

  Saved here as a founder-shared reference asset; not itself a source of
  new factual claims beyond what the referenced documents already state.

- `ur-bin-code-of-origin-axes-ai.jpg` — "UR ~ Bin Code of Origin ~ AXES AI"
