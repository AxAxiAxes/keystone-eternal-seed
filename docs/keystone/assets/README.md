This folder holds visual (image) assets shared by the founder that
illustrate KEYSTONE concepts already documented in text elsewhere in this
repository. These are branding/conceptual artwork, not engineering
diagrams or specifications — the authoritative technical and governance
content remains in the markdown documents under `docs/` and `docs/keystone/`.
