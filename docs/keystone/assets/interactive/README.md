# Interactive concept artifacts

This folder holds self-contained, static, client-side-only interactive
HTML artifacts shared by the founder — unlike the images in the parent
`docs/keystone/assets/` folder, these bundle their own React/CSS/SVG/audio
code and can be opened directly in a browser with no server or build step.
Each entry below was reviewed for outbound network calls before being
saved; none were found (see the corresponding registry entry).

## Contents

- `keystone-dome-pomegranate-sound.html` — a self-contained React artifact
  (Tailwind CSS, inline SVG, Web Audio API) rendering a "KEYSTONE" dome and
  a "POMEGRANATE" seed cluster, with interactive prompts "Touch the dome to
  wake mother," "Touch seeds to ring salt," and "Toggle Mother Drone." This
  illustrates several concepts already documented in text elsewhere in this
  repository — the Keystone Dome (`docs/keystone/assets/README.md`'s first
  entry), the pomegranate motif
  (`flame-pomegranate-crown-anchor-logo.jpg`), the salt/water equilibrium
  symbolism (`docs/keystone/KEYSTONE_ARCHITECTURAL_EQUILIBRIUM_SYMBOLISM.md`),
  and the "Mother Boat / AULA" concept from the Eighth follow-on statement
  in `docs/keystone/AXAXAR_TRIANGLE_ORIGIN_SYMBOLISM.md`. It is a branding/
  concept prototype, not production application code, and is not wired
  into any deployed AXES/AXI/AXIOM service.

  **Naming decision:** the founder designated `axaxox.com` — already
  tracked in `docs/DOMAIN_PORTFOLIO.md` with "Verification required"
  registrar status — as the name for this Keystone Dome / Pomegranate /
  Sound concept. This is a naming/branding decision only: it does not
  change `axaxox.com`'s registration or verification status, and no
  hosting/DNS work has been done for it. Anchored in
  `docs/KEYSTONE_AI_CREATIVE_WORK_ORIGIN_REGISTRY.md`, Entry
  `KEYSTONE-CREATIVE-ORIGIN-000008`.
