## What "anchor" means here

There is no network IP address to register for a piece of intellectual or
creative work, and none was looked up or verified — that would not establish
authorship or ownership of anything. What this project can and does anchor is
a **content address**: git identifies every file by the SHA hash of its exact
byte content, and every commit is timestamped by GitHub's servers when it is
received. That combination — a content hash plus an independent, third-party
server timestamp — is the real, verifiable "anchor" referred to elsewhere in
this project as the cryptographic origin anchor.
