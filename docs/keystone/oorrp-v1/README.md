# OORR-P v1 registry assets

This directory contains the append-only, machine-checkable OORR-P v1 derivative operational files:

- `registry/records/*.json` — structured records
- `registry/oorrp-hash-chain.v1.json` — deterministic canonical hash chain
- `validator.js` and `validator.test.js` — reproducible offline validation

These files are internal registry/validation artifacts. They do not replace preserved KEYSTONE source documents and do not adjudicate external legal rights.
