# AXES asset-use readiness register

**Status:** Internal asset-release control; no new asset is approved for public
use by this register
**Recorded:** 2026-09-11
**Owner:** Founder or named human delegate
**Purpose:** Maintain a minimum public/private, source, rights, and approval
record before any AXES visual, audio, prototype, or reference asset is used in
a public page, client deliverable, product, event, or provider workflow.

## Control rule

An archive location, source attribution, hash, founder-provided classification,
or AI-assisted creation history does not by itself grant publication,
reproduction, commercial-use, training, licensing, or ownership rights.
Every proposed use needs an individual decision record. If any required field
is missing, the asset remains private and is not used.

Do not place private archive assets, manifests, screenshots, source files,
credentials, client assets, or unapproved references in the public repository,
an external prompt, or a public deliverable.

The portal must expose only its explicit public routes. Its regression suite
checks that a direct private-archive path returns `404` and that an attempted
document-library traversal toward a private-archive path returns `403`.

## Individual asset-use decision record

Complete an individual record before an asset leaves approved private storage:

| Required field | Minimum record |
| --- | --- |
| Asset identifier | Stable internal ID and private source reference; do not expose restricted locations publicly |
| Proposed use | Specific page, client deliverable, product, event, or internal-only use; audience and visibility |
| Source classification | Founder-provided, contributor-confirmed, licensed/permission-based, collaborative synthesis, external/unverified, or contested |
| Rights basis | Specific creator confirmation, license, permission, public-domain basis, or unresolved status; never infer rights |
| Credit and consent | Approved public credit wording, consent scope, restrictions, expiry, and correction/removal route |
| Derivative/edit history | Whether the use is original, edited, AI-assisted, or derived; approved inputs and tool/provider history where relevant |
| Accessibility | Alt text, captions/transcript, contrast, reduced-motion/audio controls, and format review as applicable |
| Privacy and safety | Personal/sensitive data review, audience limits, and content/safeguarding decision |
| Technical quality | File format, dimensions, performance budget, security scan where applicable, and rollback/removal method |
| Human decision | Founder or named human reviewer, date, decision, and any use limitation |

## Decision states

| State | Permitted handling |
| --- | --- |
| Private preservation | Preserve privately; no public, provider, client, or product use |
| Review pending | No use until source, rights, accessibility, privacy, and human-decision fields are complete |
| Approved internal use | Use only within the approved access-controlled internal scope |
| Approved limited public use | Use only for the specified medium, audience, credit, duration, and version |
| Paused or removed | Stop the approved use; preserve the decision history and address correction, rights, or safety concern |

## Review and correction

Use the Creator Origin Constitution for provenance, consent, evidence,
challenge, and correction decisions. Recheck approval when the asset is edited,
reused in a new medium, provided to a vendor, included in a client deliverable,
or subject to a rights, privacy, accessibility, or safety concern.

This register does not authorize outreach, publication, deployment, provider
account changes, external generation, commerce, or any financial activity.
