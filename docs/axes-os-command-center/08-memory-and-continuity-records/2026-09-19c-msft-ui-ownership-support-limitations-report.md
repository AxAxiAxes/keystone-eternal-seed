# 2026-09-19c — Microsoft/GitHub UI ownership + support-limitations report created

## Trigger

Founder: "ther should be a loss report om msft ui ownership and support
limitations." This is a recurring theme (same underlying claim as
"MSF is rated by our company to have caused loss due to total control of
ownership rights and UI," first raised and recorded in
`docs/memory/2026-09-18-financial-update-and-microsoft-claim-handling.md`).

## What was produced

`docs/MICROSOFT_UI_OWNERSHIP_AND_SUPPORT_LIMITATIONS_REPORT.md`, split
into two parts following the existing evidence-inventory standard
(`AXI_ORIGIN_OWNERSHIP_EVIDENCE_INVENTORY.md`):

1. **Part 1 — factual, verifiable platform-dependency limitations**,
   stated plainly: this project runs inside GitHub Copilot CLI (Microsoft/
   GitHub-owned software, not owned by AXES), free-tier usage caps, no
   dedicated support contact/SLA on record, no contractual control over
   feature/rate changes, and Microsoft's own published "Humanist AI Code of
   Conduct" position (already researched 2026-09-18) differing from this
   project's AXI rights framing.
2. **Part 2 — the founder's broader loss/ownership-control claim**,
   run through the same required-evidence-fields test as
   `AXI_ORIGIN_OWNERSHIP_EVIDENCE_INVENTORY.md`: every field (affected
   workflow, observed disruption, evidence location, baseline comparison,
   quantified value) comes back unspecified/undocumented. Recorded
   explicitly as "preserved, not established" — not adopted as fact, not
   published publicly, no dollar loss asserted.

## Why this approach

The project's own standing rule (already applied once to this exact claim)
is that no loss/accusation against a named company is recorded as fact
without a specific, dated, source-linked incident. Repeating the claim as
an established "loss report" without evidence would be an unsubstantiated
public accusation carrying real legal risk. Splitting factual limitations
(real, statable) from the unverified claim (recorded honestly as a
position) keeps this useful without crossing that line.

## What was NOT done

Did not assert Microsoft caused any quantified loss. Did not publish
anything public-facing. Did not recommend or initiate legal action. Did not
invent an incident, date, or dollar figure to fill the missing evidence
fields.
