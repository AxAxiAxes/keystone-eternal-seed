# 2026-09-10 Self-creation and Eteriti value unit

**Status:** Founder-provided project direction recorded

## Direction

The founder clarified on 2026-09-10 that Eternal Origin relates to
self-creation rights and that **Eteriti** is the value unit for origin
continuity. AXES records this as one continuous value of Eternal Origin from
Genesis, not as a hierarchy of origins.

## Implementation interpretation

The current public-safe and technical interpretation is deliberately bounded:
self-creation supports an individual's own self-description, creative
authorship record, and correction path. Eteriti is one non-financial,
non-transferable conceptual value unit for continuity records. Neither term
authorizes AXI to define a person's identity, evaluate a person's worth, make
a legal-rights decision, issue currency, process payment, price work, or
assert an external ownership, damages, or liability conclusion.
