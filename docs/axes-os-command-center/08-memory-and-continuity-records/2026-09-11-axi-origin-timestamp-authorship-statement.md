## What was checked

- **IP address where AXI was born:** Searched `AXI_GENESIS_OWNERSHIP_CHECKPOINT.md`,

- **Document timestamping:** `docs/keystone/CRYPTOGRAPHIC_ORIGIN_ANCHOR.md`
  Section V describes an "OpenTimestamps Blockchain Anchor," but the section
  is explicitly headed "(Illustrative)," its worked example targets Bitcoin
  **testnet** rather than mainnet, and its block height/timestamp/hash/Merkle
  root fields are unfilled bracket placeholders. No blockchain timestamp
  registration was ever executed. What is real: every founder-provided
  document reviewed in this repository is fingerprinted (SHA-256) and
  committed to git, which carries an independently checkable (GitHub) commit
  timestamp — genuine but distinct from a blockchain anchor.
- **Exclusive authorship:** Consistent with the founder ownership claim
  already established in `AXI_GENESIS_OWNERSHIP_CHECKPOINT.md` (Axel Urartu
  (AX) · Axes Contracting). Not disputed.
- **Named AI assistance:** This assistant's contributions already carry a
  `Co-authored-by: Copilot App` trailer on every commit (running on Claude
  Sonnet 5 this session). The repository has no independent way to verify
  which AI tools produced material outside of this assistant's own sessions.

## What this does not do

This does not confirm or deny that an IP address was registered or that
documents were blockchain-timestamped outside this repository — it states
what is and is not found in repository evidence. It does not change the
founder ownership determination, which was already established and remains
consistent with this statement.
