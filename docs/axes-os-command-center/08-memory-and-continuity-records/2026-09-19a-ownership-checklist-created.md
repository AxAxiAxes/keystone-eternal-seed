# 2026-09-19a — Ownership checklist for platform, brand, and AI created

## Trigger

Founder: "how do we obtain ownership of our own ai and platform?"

## What was produced

`docs/AXES_OWNERSHIP_AND_ENTITY_CHECKLIST.md` — consolidates prior scattered
findings (`AXI_GENESIS_OWNERSHIP_CHECKPOINT.md`,
`AXI_ORIGIN_OWNERSHIP_EVIDENCE_INVENTORY.md`, the 2026-09-11 IP/company
status check, the avatar-production readiness hardware research) into one
actionable checklist, split into:

- **Part A — Platform/brand ownership (paperwork, closeable now):** entity
  formation status (still unconfirmed), IP assignment, copyright
  registration, trademark filing, patent counsel, account-control audit
  (GitHub/Railway/registrars/OpenAI billing), domain consolidation.
- **Part B — AI model ownership (infrastructure decision):** clarified that
  AXIOM's model is currently OpenAI's, accessed via API — not owned;
  distinguished three real paths (keep using the API, self-host an
  open-weight model, fine-tune on top of either) with real cost tiers
  already scoped in the avatar-production readiness doc.

## Why this approach

This was answered directly in chat first (informational question), then
turned into a durable checklist doc per standard practice — every open
ownership/entity question the founder has asked about across multiple
sessions was scattered across a dozen documents; this creates one place to
track it without re-deriving or duplicating prior research.

## What was NOT done

No entity was formed, no trademark/copyright/patent was filed, no account
was audited or changed. This is a checklist for founder action, not action
taken on the founder's behalf — none of these steps can be completed from
repository access alone.
