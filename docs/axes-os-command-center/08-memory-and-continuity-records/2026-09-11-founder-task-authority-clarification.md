# Founder task authority clarification

**Recorded:** 2026-09-11
**Status:** Founder control framing clarified for the private business-metrics foundation.

## Clarification

The founder alone controls AXI-role work assignment/removal, task approval,
suspension, and reactivation through the protected operational process. AXI
roles execute only the bounded work that the founder assigns and approves; they
cannot initiate or perform those controls for themselves or other roles.

## Implementation relevance

The protected Automation Console and the business-metrics, automation,
engine-integration, and agent-origin records now state this boundary. No agent
assignment, capability, scheduler setting, deployment, external account, or
external data source was changed.
